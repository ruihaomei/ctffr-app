# Model

> **For research use only.** This software is not a medical device and is not intended for standalone clinical diagnosis or treatment decisions.

The model estimates CT-derived fractional flow reserve. CT-FFR is itself a computational estimate of invasive fractional flow reserve; this software does not predict invasive FFR.

## Locked inference object

The application ships model version `4.0.0-relaxed-shrinkage-regressor-20260805`: a fitted preprocessing pipeline and `HistGradientBoostingRegressor` for continuous CT-FFR. It is inference-only and contains no training code or patient rows. SHA-256 is verified against `artifacts/model_metadata.json` before the model loads.

Users supply 20 predictor-bearing raw fields plus `case_id`. Automatic derivation produces the ordered 23 model input columns. Fitted imputation, scaling, and encoding expand these to 48 design-matrix columns. The user interface deliberately discusses only the 20 fields the user supplies.

The development analysis used 615 lesions from 411 patients with patient-grouped out-of-fold evaluation. The external cohort contained 183 lesions from 98 patients. The external cohort also served as an acceptance check for the prespecified development-OOF ICC-ranked configuration, so results should not be framed as untouched independent confirmation of every model-selection choice. Reported regression performance includes external MAE 0.063 and RMSE 0.077; prospective and multi-center generalizability remain unestablished.

## Why app SHAP differs slightly from manuscript SHAP

The manuscript analysis used 64 real development-cohort rows as its SHAP background. Those rows cannot be distributed because doing so would publish row-level patient measurements. The application therefore uses 25 k-means centroids computed from the same 23 model features. A centroid is an aggregate cluster center, not a patient record.

This privacy-preserving substitution was measured before release:

| Quantity | 64 real rows | 25 centroids | Difference |
|---|---:|---:|---:|
| SHAP base value | 0.75341 | 0.74707 | -0.00634 (about 0.006) |
| Largest change in one feature contribution | — | — | 0.0086 |
| Top-five predictor set | Same set | Same set | Only ranks 2 and 3 swapped |

Consequently, a chart generated by this app can differ slightly from the manuscript chart for the same feature profile. The differences are small and quantified, and the central ranking is stable. The alternative would be releasing actual patient rows, which is not acceptable. The recommended release decision is to retain centroid-based SHAP with this disclosure.

SHAP contributions are in predicted CT-FFR units. The base value plus all 23 contributions reconstructs the model prediction; an automated test enforces additivity to `1e-6`. Contributions describe this fitted model and do not imply causality.

## Scope and limitations

- The reporting reference is predicted CT-FFR at 0.80; this is not a direct invasive FFR measurement or a standalone diagnosis.
- Inputs beyond the observed study range are extrapolations and receive warnings.
- Samples and golden cases are synthetic and are not examples of clinical performance.
- No runtime data or telemetry leave the user's machine.
